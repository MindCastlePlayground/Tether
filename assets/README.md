# Tether identity

Tether connects agents and scripts to the browser people already use. The mark folds a teal tether around a navy stem, forming a lowercase **t**. Its gap represents a connection between two distinct sides.

- Name: **Tether**
- Tagline: **Your browser. Connected.** / **连接你的浏览器。**
- Ink: `#182C46`; lagoon: `#007F82`; paper: `#F3F8F9`; line: `#D6E4E7`; muted: `#526778`.
- Display type: Trebuchet MS, with Segoe UI fallback. Interface type: Segoe UI, with system fallback.
- `logo.png`: original transparent master generated with the built-in imagegen tool.
- `logo-256.png`: documentation-size export.
- `../prototype/extension/icons/icon-{16,32,48,128}.png`: browser-extension exports of the same mark.
