# Tether identity

[简体中文](README.zh-CN.md)

Tether connects agents and scripts to the browser people already use. The mark folds a teal tether around a navy stem to suggest a lowercase **t** and a connection between two distinct sides.

- Name: **Tether**
- Tagline: **Your browser. Connected.** / **连接你的浏览器。**
- Colors: ink `#182C46`, lagoon `#007F82`, paper `#F3F8F9`, line `#D6E4E7`, muted `#526778`.
- Display type: Trebuchet MS with Segoe UI fallback. Interface type: Segoe UI with system fallback.
- `logo.png` is the transparent master; `logo-256.png` is a documentation-size export.
- `../prototype/extension/icons/` contains browser extension icon exports.

Preserve the original proportions and transparent background. Place the mark on a light background so both colors remain visible. The PNG master is raster artwork, not editable vector art.
