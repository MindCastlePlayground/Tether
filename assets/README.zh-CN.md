# Tether 品牌识别

[English](README.md) · [品牌验收](branding-verification.zh-CN.md) / [Brand verification](branding-verification.md)

Tether 将智能体和脚本连接到用户已有的浏览器。标志以青绿色系带环绕深蓝色竖笔，形成小写 **t**；间隙表示两个独立端点之间的连接。

- 名称：**Tether**
- 标语：**Your browser. Connected.** / **连接你的浏览器。**
- 墨色：`#182C46`；湖青色：`#007F82`；纸白：`#F3F8F9`；线条：`#D6E4E7`；次要文字：`#526778`。
- 展示字体：Trebuchet MS，回退到 Segoe UI。界面字体：Segoe UI，回退到系统字体。
- `logo.png`：使用内置 imagegen 工具生成的透明原图。
- `logo-256.png`：文档尺寸导出图。
- `../prototype/extension/icons/icon-{16,32,48,128}.png`：同一标志的浏览器扩展尺寸导出图。

使用时保留原始比例和透明背景，并置于浅色背景上以确保两种颜色清晰可见。扩展弹窗以标志作为识别元素，采用克制的字体和简洁的布局。

生成提示词：

> 使用场景：logo-brand。为一款名为 Tether 的开发者工具创作一个精致、独立的图标；该工具将 AI 智能体连接到现有浏览器标签页。设计为独特的抽象互锁系带/折叠丝带，隐约形成小写 t：两条粗实、平滑弯曲的链环交叠，中间留有清晰细小的负空间间隙，一条深午夜蓝 #182C46，另一条饱和湖青 #007F82。轮廓紧凑、平衡、自信，在 16px 尺寸仍可辨识，适合作为浏览器扩展图标。纯色扁平设计，边缘清晰、近似矢量；无渐变、阴影、发光、文字、单独书写的字母、字标、浏览器框架、样机或装饰细节。将单个标志置于真正透明的正方形画布中央，四周留出均匀宽裕的边距，标志占画布约 72%。避免类似加密货币标志。呈现专业、独立软件的品牌特质，低调而易记。

生成原图带有轻微明暗效果；它是栅格品牌素材，不是可编辑矢量图。各尺寸导出保留了原图外观。
