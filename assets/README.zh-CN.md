# Tether 品牌识别

[English](README.md)

Tether 将智能体和脚本连接到用户已有的浏览器。标志以青绿色系带环绕深蓝色竖笔，隐约形成小写 **t**，表达两个独立端点之间的连接。

- 名称：**Tether**
- 标语：**Your browser. Connected.** / **连接你的浏览器。**
- 颜色：墨色 `#182C46`、湖青色 `#007F82`、纸白 `#F3F8F9`、线条 `#D6E4E7`、次要文字 `#526778`。
- 展示字体：Trebuchet MS，回退到 Segoe UI。界面字体：Segoe UI，回退到系统字体。
- `logo.png` 是透明背景原图；`logo-256.png` 是适用于文档的尺寸导出图。
- `../prototype/extension/icons/` 包含浏览器扩展图标导出文件。

使用时保留原始比例和透明背景，并置于浅色背景上以确保两种颜色清晰可见。PNG 原图为栅格图，不是可编辑矢量图。
