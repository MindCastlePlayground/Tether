# Tether 国际化

[English](I18N.md) · [项目介绍](../README.zh-CN.md) · [弹窗指南](../prototype/README.zh-CN.md)

扩展提供 Chrome 语言目录：英文（`_locales/en`）和简体中文（`_locales/zh_CN`）。弹窗通过 `chrome.i18n.getUILanguage()` 读取 Chrome 界面语言，并从这些消息目录显示文本；manifest 的扩展名称和描述使用 `__MSG_...__` 本地化引用，使 Chrome 扩展界面能显示对应语言。

弹窗提供三种选择：跟随浏览器（`auto`）、英文（`en`）和简体中文（`zh-CN`）。所选值保存在 `chrome.storage.local`；明确选择语言后，后续打开弹窗会优先使用该语言，选择 `auto` 则继续跟随浏览器。没有已保存的值时也跟随浏览器语言。包括无障碍标签、状态和错误文案在内的用户文本来自语言目录；协议值、存储键及内部标识保持语言中立。磁盘上的 Chrome 语言目录名为 `zh_CN`，而弹窗保存的偏好值为 `zh-CN`。

## 添加或修改语言

1. 在扩展的 `_locales/<locale>/messages.json` 下添加语言目录，保留现有语言文件使用的消息键和占位符定义。
2. 翻译消息内容，包括描述、无障碍名称、状态文案。协议标识和代码示例保持原样。
3. 在 `prototype/extension/i18n.js` 中导入新语言文件，并扩展 `Locale.Catalogs`、`Locale.normalize()` 和 `Locale.valid()`。只有计划允许用户手动选择的语言才加入弹窗语言选项。保存的偏好值应保持稳定且对应具体 locale。
4. 按需更新 manifest 中本地化名称和描述所引用的消息。
5. 若选择或持久化行为有变化，同时更新本页和[英文版](I18N.md)。
6. 检查本地链接，并比较所有语言目录中的消息键/占位符是否一致。运行时或构建验证应属于实现变更；本文本身不表示相关检查已经执行。

中文浏览器语言（包括 zh-TW）当前使用简体中文目录，其他未支持语言回退英文。工具栏标题和扩展元数据独立跟随浏览器语言。

语言偏好仅影响弹窗显示，不改变授权策略、Broker 协议或浏览器语言设置。

## MCP 和安装脚本

仓库根目录安装器通过 `--language en|zh-CN` 设置帮助/状态文案及生成的 MCP 配置。省略选项时跟随 Node 系统 locale，不读取 `BB_LANGUAGE` 来选择安装器语言。见[安装指南](INSTALL.zh-CN.md)和[安装器验收](INSTALL-VERIFICATION.zh-CN.md)。弹窗偏好、安装器选项和 MCP 环境变量相互独立。

在 PowerShell 中设置 `$env:BB_LANGUAGE = 'zh-CN'` 或 `$env:BB_LANGUAGE = 'en'`，再启动 MCP 或运行安装脚本。MCP 客户端配置可在 `command` 同级添加 `"env": { "BB_LANGUAGE": "zh-CN" }`。未指定时，MCP 使用 Node 系统 locale，Python 初始化脚本使用其系统 locale，PowerShell 使用当前区域设置。未知的显式值回退英文。API 名称、JSON 字段、错误码和诊断证据保持原样。

启动器生成脚本现已将 `BB_LANGUAGE` 传给子进程。此前生成的 `.local/mcp.exe` 需更新：停止 MCP 客户端后，仅删除 `.local/mcp.exe`，从 `prototype/` 执行 `powershell -ExecutionPolicy Bypass -File scripts/launchers.ps1`。脚本只生成缺失的启动器，不启动程序，不重新生成凭据，也不需要启动 Broker。

## 验证

从仓库根目录执行 `npm run docs:check`，检查所有发布的 Markdown 是否有英文/简体中文配对、相互切换语言的导航、对应的标题层级、表格和代码块结构，以及有效的本地链接。修改任一语言时还需人工核对译文含义；结构检查不能证明语义等价。命令、RPC 名称、JSON 字段、路径和验收边界应保持一致；解释性代码注释也应与正文一样翻译。仅 `SKILL.md` 包含技能发现 frontmatter；`SKILL.zh-CN.md` 是对应的中文阅读版。本地被忽略的迁移记录和诊断日志不属于发布文档。

从 `prototype/` 执行 `npm run build`，再执行 `node --test --test-isolation=none test/i18n.test.mjs test/extension.test.mjs`。`node scripts/brand-preview.mjs` 使用隔离无头 Chrome 检查双语、偏好保存、自动语言识别、授权操作、标签选择、错误状态和布局。它模拟扩展运行时，不启动 Native Host 或 Broker。报告和截图位于 `assets/`，不能代替真实已安装扩展的验收。
