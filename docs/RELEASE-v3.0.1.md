# Tether 3.0.1

[简体中文](RELEASE-v3.0.1.zh-CN.md) · [Overview](../README.md)

Fix managed-runtime builds failing to locate the localization generator: ship the script inside the runtime and use a runtime-relative build path. Installer, runtime, extension and sandbox versions are aligned at 3.0.1.

Includes the [3.0.0 features](RELEASE-v3.0.0.md) and updated Skill guidance for intent-based subagent delegation, returning results or handing the page back for the parent to read.
