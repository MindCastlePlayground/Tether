# Tether 3.1.0

[English](RELEASE-v3.1.0.md) · [项目介绍](../README.zh-CN.md)

## 命名标签页组

- **问题：** 自动创建的任务组只有随机名称，多任务并行时难以辨认。
- **根因：** `requestSession` 没有组名参数，扩展在创建组时固定生成默认名称。
- **解决方案：** 增加 `groupName` 参数和“智能体命名标签组”独立开关。开启时使用指定名称，关闭或未提供名称时使用默认名称。支持 1–80 字符，拒绝控制字符和空白名称，去掉首尾空白。
- **影响点：** 新建任务组、接管会话通过 `createTab` 创建的独立任务组，以及 MCP/Node SDK 请求参数。用户已有组不改名，同名组不会合并或扩大授权。开关变化只影响后续组创建。

## 直接接管现有标签页

- **问题：** 现有标签页的直接接管与新任务组的自动批准共用一个开关，无法分别控制。
- **根因：** `attachExisting` 指定 `tabId` 后仅检查自动批准总开关。
- **解决方案：** 增加“直接接管标签页”独立开关。关闭后请求进入人工审批，`availableTabs` 不再向 Agent 枚举标签页；开启后仍须满足自动批准总开关与策略规则，策略 `ask` 继续要求人工批准。需要审批的请求正常发送通知。
- **影响点：** 标签页发现、会话请求、审批通知和扩展设置。不会导航、移动或重命名被接管的标签页，释放会话后保留标签页。已有授权不因切换开关而撤销，可通过会话列表手动撤销。

两个新开关默认开启，保存到本机，并在扩展重载后恢复。根安装器、运行时、扩展与专用沙箱版本统一为 `3.1.0`。
