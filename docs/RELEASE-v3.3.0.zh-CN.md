# Tether 3.3.0

[English](RELEASE-v3.3.0.md) · [项目](../README.zh-CN.md)

## 操作轨迹与预设

- **问题：** 浏览器操作无法保存为可复用预设，也不能导出为不依赖 Tether 运行的脚本。
- **根因：** `records` 只保存操作元数据。没有步骤轨迹、已保存的预设，也没有把这些步骤编译成 Playwright 脚本的过程。
- **解决方案：** 记录 `navigate`、`click`、`fill`、`wait`、`assert`，包括填写值。`preset` 可保存、读取、列出、删除、导出并重跑这些步骤。导出生成可独立运行的 Playwright 脚本。在 Tether 上重跑时，遇到被拒绝、不确定或失败的步骤即停止，不自动重试。
- **影响点：** 轨迹和预设按凭据保存在内存中，Broker 重启后清空。导出的文件是持久副本。`records` 仍排除页面内容和参数。填写值保持明文，因为使用环境是测试环境。

## 已采集接口的 HTTP 导出

- **问题：** 网络检查可以列出并分页读取响应，但不能把已采集的交换交给 Agent 作为 HTTP 文本。
- **根因：** 采集只支持 `start`、`list`、`detail`、`body`、`stop`、`clear`。
- **解决方案：** 增加 `network` 的 `op: http`。它把采集缓冲里已有的请求和响应写成 `.http` 文本，包含正文。Agent 之后自行整理这些文本。
- **影响点：** 静态资源、统计和应用调用都会出现。`start` 之前不会采集。缓冲为空时导出空文本。导出不编造调用，也不编译请求流程。

根安装器、运行时、扩展与专用沙箱版本统一为 `3.3.0`。
