# Tether 3.4.0

[English](RELEASE-v3.4.0.md) · [项目](../README.zh-CN.md)

## 更新后的回退

- **问题：** 升级或更新之后如果 runtime 无法使用，没有上一份可运行的副本可以启动。
- **根因：** 升级会原地替换 runtime 源码，然后重新构建 `dist` 和 `node_modules`。它保留 `.local` 和 `.venv`，但不保留上一份程序。
- **解决方案：** 替换就绪的 runtime 之前，在 `<runtime>/.rollback` 保存一份可运行副本，包含源码、构建产物和已安装的 Node 模块。`tether rollback` 或 runtime 目录中的 `rollback.cmd` 会把这份副本换回去。再执行一次则回到被换下的版本。升级中断不会覆盖已保存的副本。
- **影响点：** 只保留最近的上一版本；下一次对就绪 runtime 完成的升级会替换它。凭据、证书、策略和 `.venv` 留在原处。已记录的扩展目录会被恢复出的扩展覆盖。回退不需要网络。

根安装器、运行时、扩展与专用沙箱版本统一为 `3.4.0`。

## 验证

2026-11-11：77 项根测试和中英文档检查通过。升级与回退测试覆盖了只保留一份副本、来回换回、失败时把文件放回、升级中断，以及 dry-run。
